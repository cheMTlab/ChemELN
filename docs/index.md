# CheMTlab

CheMTlab is an open-source (AGPL-3.0) electronic lab notebook with an interactive chemical inventory. Each institution installs it on a server it controls.

- **Users** need only a web browser. On phones and tablets they can "Add to Home Screen" to install it as an app.
- **IT staff** install it with one script on a Linux server or VM. See [Installation](install.md).
- **Data** stays on that server, with encrypted backups to storage the institution owns. See [Data safety](data-safety.md).
