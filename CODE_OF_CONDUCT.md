# Code of Conduct

CheMTlab follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and inclusive, assume good faith, and focus on what is best for the community. Harassment of any kind is not tolerated.

Report unacceptable behaviour to the maintainers through a private GitHub security advisory or the contact address listed on the project page. All reports are handled confidentially.
